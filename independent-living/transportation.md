# Transportation

Busses are cool. They're like trains, but for the road...and one car...and no train horn...and no tracks..and they're smaller. Okay, they're not like trains at all. But busses are good for the environment. So try them out. Portland without a car is doable. The trick is planning the return trip before leaving.

## Quick Answer

- Use OtterBus for campus-connected trips when it is running.
- Use TriMet for buses, MAX, and broader Portland travel.
- Use Hop Fastpass or contactless payment for fares.
- Check service alerts before important trips.
- Always know how you will get back.

## Before Going Somewhere New

- [ ] Check route.
- [ ] Check return route.
- [ ] Check when service stops.
- [ ] Charge phone.
- [ ] Have a backup transportation option.
- [ ] Bring rain gear.

## OtterBus

[OtterBus](https://www.lclark.edu/offices/transportation_and_parking/shuttle/) is Lewis & Clark's free shuttle service connecting campus, downtown, and public transportation.

Schedules and routes can change. Verify current details before relying on them.

## TriMet

TriMet runs Portland-area buses, MAX light rail, WES, and trip planning tools.

- [TriMet Trip Tools](https://trimet.org/tools/) — Trip planning, arrivals, alerts, and payment tools.
- [TriMet Trip Planner](https://trimet.org/home/planner/) — Step-by-step route planning.
- [Hop Fastpass](https://support.trimet.org/hc/en-us/articles/4417256941339-What-is-Hop-Do-I-need-a-Hop-card-to-ride-) — How tapping to pay works.
- [Current fares](https://trimet.org/fares/allfares.htm) — Verify current costs before budgeting.

## Transfers and Route Planning

When planning a trip, check:

- where to board,
- where to transfer,
- how long the transfer is,
- whether the return route still runs later,
- whether there are service alerts.

## Late Night or Stranded

If you miss the last bus:

- [ ] Move to a safe, populated place.
- [ ] Preserve phone battery.
- [ ] Check another route.
- [ ] Consider rideshare, taxi, or trusted pickup.
- [ ] Contact someone if you feel unsafe.

## Airport

Use the OtterBus page and TriMet Trip Planner for current airport guidance. Leave extra time.

## Groceries and Pharmacies

For new errands:

- plan the route before leaving,
- check store hours,
- make sure the return route works with bags,
- avoid buying more than you can carry.

## Bikes, Scooters, and Walking

Use lights, helmets where appropriate, and visible clothing.

Rain changes everything: braking, visibility, comfort, and motivation.

# Four-Year Roadmap

> This is guidance, not a rigid schedule. Opportunities can happen earlier or later.

## Quick Answer

- First year: learn the system.
- Sophomore year: deepen involvement.
- Junior year: build serious experience.
- Senior year: launch the next step.

## First Year

Focus:

- learn how college works,
- build study habits,
- meet faculty,
- explore clubs,
- establish accommodations if needed,
- start a brag file,
- explore interests.

Good moves:

- [ ] Visit office hours.
- [ ] Try Math Club and Russian Club.
- [ ] Use SQRC before exams.
- [ ] Make a four-year draft plan with an advisor.
- [ ] Learn Portland basics.

## Sophomore Year

Focus:

- tutoring,
- departmental involvement,
- early research,
- leadership,
- internships,
- deeper faculty relationships,
- language opportunities.

Good moves:

- [ ] Ask about SAAB tutoring.
- [ ] Look for summer research.
- [ ] Explore CLS timing.
- [ ] Update resume and brag file.

## Junior Year

Focus:

- research,
- major internships,
- study abroad,
- graduate school exploration,
- recommendation-letter relationships,
- conferences.

Good moves:

- [ ] Talk with faculty about graduate school fit.
- [ ] Attend talks or conferences if possible.
- [ ] Ask about recommendation letters early.
- [ ] Keep track of application deadlines.

## Senior Year

Focus:

- graduate applications,
- jobs,
- recommendations,
- capstone or research,
- financial transition,
- housing and post-college planning.

Good moves:

- [ ] Finalize resume/CV.
- [ ] Request recommendations early.
- [ ] Track every deadline.
- [ ] Make a post-graduation budget.
